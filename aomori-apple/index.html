UNIT 01 處理流程

真實照片→COCO-SSD→Apple 篩選→NMS→多顆計數→輸送帶集中
① Webcam 即時影像輸入攝影機維持 640×480 顯示，AI 推論與畫面更新分開執行，避免連續推論阻塞 Webcam 顯示。
② COCO-SSD 物件偵測模型直接輸出物件類別、信心度與 Bounding Box；本單元只保留 class = Apple 的偵測結果。
③ 整張 + 分區放大偵測除了整張畫面，系統也會將畫面切成 4 個重疊區域再次偵測，讓紙本教材中的較小蘋果在模型輸入中占有更大的比例。
④ NMS 去除重複框並計數同一顆蘋果可能同時被整張與分區偵測找到，NMS 會保留信心度較高的框並移除重複框，最後才統計蘋果數量。
⑤ 下一步轉場按下下一步後，凍結目前的物件偵測 Bounding Box，擷取各顆蘋果 ROI 並集中到輸送帶；Bar Code 留到 UNIT 02 才建立。
