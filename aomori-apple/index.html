UNIT 01

蘋果偵測與數量統計

利用物件偵測找出畫面中的蘋果，觀察 AI 如何從影像中辨識物件位置並完成數量統計。

Object Detection · Bounding Box · Counting
進入 UNIT 01
UNIT 02

大小量測與建立 Bar Code

利用 Apple 與 Stop Sign 的物件偵測結果進行比例換算，完成尺寸量測並建立產品唯一識別碼。

Object Detection · Calibration · Bar Code
進入 UNIT 02
UNIT 03

顏色與飽滿度檢測

讀取 UNIT 02 的產品 ID，在同一筆蘋果履歷中加入紅色比例、平均飽和度與顏色等級。

Color Analysis · Saturation · Product Record
進入 UNIT 03
UNIT 04

瑕疵檢測

針對蘋果表面進行瑕疵判斷，將檢測結果接續寫入同一筆產品履歷，作為後續分級依據。

Defect Detection · Inspection · Traceability
進入 UNIT 04
UNIT 05

智慧選果與分級

整合尺寸、顏色與瑕疵等檢測資料，模擬智慧選果系統如何根據多項條件完成最終分級與產線決策。

System Integration · Decision Logic · Smart Sorting
