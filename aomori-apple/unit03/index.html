鮮明
本單元的「飽滿度」指 HSV 色彩空間中的 Saturation（飽和度），數值越高代表顏色越濃、越鮮明；不是果實重量、成熟度或含水量。
紅色主導度：使用 R ÷ (R+G+B) 表示紅色在像素三色中的相對占比，作為輔助判斷。
顏色等級：A 級改採多條件判斷：高紅色覆蓋率 + 適中的飽和度 + 足夠鮮豔度，或符合高紅色主導度／深紅覆蓋條件；B 級維持紅黃均衡判斷；其餘為 C 級。
AI 找到 Apple 後會自動收集 5 次顏色樣本。取樣完成後即可鎖定結果。

工程流程

INPUT → OUTPUT
1. Object Detection：先找到 Apple 的 Bounding Box。
2. ROI：只分析蘋果所在區域，排除大部分背景。
3. HSV：把影像轉成色相 Hue、飽和度 Saturation、亮度 Value。
4. Result：輸出紅色比例、顏色飽滿度與紅色鮮豔度。
5. Traceability：產線模式下，逐筆選擇 UNIT 02 的 Bar Code，只把顏色判定等級寫入該筆資料。
顏色門檻為本課程的教學示範，用於比較三張不同紅色程度的蘋果教材，不代表青森實際商業選果標準。
