瑕疵分析：先排除白色背景、蘋果邊緣與果梗區，再找出相對於整顆蘋果較暗、偏褐色的像素，最後用連通區塊把零散雜訊合併成可解釋的瑕疵區域。
跨站紀錄：畫面上的面積比、區塊數與最大瑕疵區只供教學觀察；寫入產品履歷時只新增「瑕疵判定」。
AI 找到 Apple 後會自動收集 5 次瑕疵樣本。取樣完成後即可鎖定結果。

工程流程

INPUT → OUTPUT
1. Object Detection：先用 AI 找出 Apple 的 Bounding Box。
2. ROI Mask：保留蘋果中央有效區域，排除背景、邊緣陰影與果梗／果梗凹槽的自然暗區。
3. Defect Candidate：比較亮度與色相，找出暗斑／褐斑候選像素。
4. Connected Components：把相鄰候選像素合併，過濾太小的雜訊區塊。
5. Traceability：產線模式只將瑕疵判定追加到同一筆 Bar Code 資料。
本頁門檻是教學示範，不代表青森實際商業選果標準。為降低誤判，果梗附近的小型自然凹槽暗區不列為瑕疵；之後仍可依「正常／輕微／明顯瑕疵」教材照片再做校調。
