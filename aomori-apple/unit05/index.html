代表尺寸 = (寬度 + 高度) ÷ 2。開始智慧分級後，規則會鎖定，避免同一批蘋果使用不同門檻。
第一關｜瑕疵明顯瑕疵 → 淘汰；輕微瑕疵 → 最高只能到一般。
第二關｜顏色A｜深紅飽滿可進特選；A/B 可進優選；C 會降為一般。
第三關｜尺寸良好蘋果中，大果＋A → 特選；中果以上＋A/B → 優選；其他 → 一般。
此門檻只用於教學模擬。可以在開始分級前調整大果與中果的尺寸門檻。

工程流程

INPUT → DECISION → OUTPUT
INPUT：Bar Code ID、尺寸、顏色等級、瑕疵判定。
DECISION：利用條件式決策規則整合尺寸、顏色與瑕疵，一次完成分級決策。
OUTPUT：特選、優選、一般、淘汰。
TRACEABILITY：只新增 finalGrade，保留完整產品履歷。
本單元刻意使用可解釋的條件式決策，而不是再加入新的黑箱模型，讓學生理解「AI 感測結果如何進入工程決策」。
