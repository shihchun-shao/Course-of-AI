模型與攝影機設定

Colab 訓練完成後，如何匯出模型？
from ultralytics import YOLO
from google.colab import files

model = YOLO("/content/runs/detect/train/weights/best.pt")  # 改成你的 best.pt 路徑
onnx_path = model.export(format="onnx", imgsz=640, dynamic=False, simplify=True)
files.download(onnx_path)
下載完成的 .onnx 檔，回到本頁載入即可。此頁適用 Ultralytics YOLO 物件偵測模型，建議使用 640 × 640 輸入尺寸。

尚未選擇模型（建議使用 nano／n 等級、輸入尺寸 640 的 ONNX）

只有一類就輸入一行；多類時每行輸入一類，順序須和訓練資料一致。可從資料集的 classes.txt 複製；留空時以 class_0、class_1…顯示。
