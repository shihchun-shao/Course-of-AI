KLT 教學流程

① Select ROI框選要追蹤的物件。
② Shi-Tomasi Features在 ROI 中找亮度變化明顯、容易追蹤的角點。
③ Lucas-Kanade利用相鄰影格估計每個特徵點的水平與垂直位移。
④ Outlier Filtering移除與主要運動方向差異太大的錯誤特徵點。
⑤ Update Bounding Box利用特徵點的共同位移更新追蹤框。

核心概念

Ix·u + Iy·v + It = 0
u、v 是特徵點在 x、y 方向的移動量。高中階段可以先理解成：「觀察一小塊鄰近 Pixel，找出最合理的共同移動方向」。

測試建議

先用書本、紙盒、鍵盤、電路板、印有文字或 Logo 的物件測試。單色、反光或沒有紋理的物件較不適合 KLT。
