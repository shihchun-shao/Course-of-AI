BiSeNet v2 本頁使用 COCO-Stuff 171-class BiSeNet v2 ONNX 模型與 ONNX Runtime Web，在使用者自己的瀏覽器中執行 Pixel-level Semantic Segmentation。

BiSeNet v2 如何進行語意分割？

① Input Image取得 Webcam 畫面並縮放成模型需要的 Input Size。
② Detail Branch保留空間細節，例如物件邊界、輪廓與局部影像結構。
③ Semantic Branch擷取高階語意資訊，判斷畫面中的人物、家具、牆面、地板、物品與背景類別。
④ Bilateral Guided Aggregation融合 Detail Branch 與 Semantic Branch，兼顧邊界與語意。
⑤ Pixel Classification對影像中的每一個 Pixel 從 171 個類別中進行判斷。
⑥ Segmentation Mask相同類別的 Pixel 使用相同顏色，形成完整的 Semantic Mask。
⑦ Mask Overlay將彩色 Semantic Mask 半透明疊回原始畫面，方便觀察 AI 判斷區域。

COCO-Stuff 適合教室的類別例子

person、chair、couch、dining table、laptop、mouse、keyboard、cell phone、book、bottle、 cabinet、carpet、ceiling、counter、cupboard、curtain、desk-stuff、door-stuff、 floor-other / tile / wood、light、paper、shelf、table、wall-*、window-* 等。

為什麼不是 Cityscapes？

Cityscapes 主要針對道路與戶外駕駛場景；COCO-Stuff 涵蓋 80 個 Thing 類別與 91 個 Stuff 類別， 更適合辦公室、電腦教室與一般生活場景。

使用提醒

Webcam 需要 HTTPS 或 localhost。第一次開啟需要下載 ONNX Runtime Web 與 BiSeNet v2 ONNX 模型。 Chrome / Edge 若支援 WebGPU，系統會優先嘗試 WebGPU；失敗時改用 WebAssembly。按下「停止分割」後，網頁會釋放 ONNX Runtime Session、停止 Webcam 並清空影像緩衝區，以降低模型繼續占用記憶體的情況。
