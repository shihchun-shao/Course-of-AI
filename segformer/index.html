MaskFormer 本頁使用 MaskFormer + ResNet-50 + COCO-Stuff 171-class FP32 模型。模型在背景 Web Worker 執行，停止後會釋放 Pipeline 並終止 Worker。

MaskFormer 如何進行語意分割？

① Input Image 取得 Webcam 畫面，由模型的 Image Processor 自動進行 Resize、Normalize 與 Tensor 建立。
② ResNet-50 Backbone 利用 ResNet-50 擷取影像中的多尺度視覺特徵，建立後續遮罩與類別判斷所需要的特徵表示。
③ Pixel Decoder 將 Backbone 的特徵轉換為適合 Pixel-level 預測的特徵，保留物件邊界與空間資訊。
④ Transformer Decoder 透過 Transformer Decoder 建立一組 Mask Embeddings，讓模型同時學習區域遮罩與其語意類別。
⑤ Mask Classification 每個預測 Mask 會搭配一個 COCO-Stuff 語意類別，再整合為每個 Pixel 的最終分類結果。
⑥ Semantic Mask 相同語意類別的 Pixel 使用相同顏色，形成完整的 Segmentation Mask。
⑦ Mask Overlay 將彩色 Semantic Mask 半透明疊回原始 Webcam 畫面。

使用提醒

Webcam 需要 HTTPS 或 localhost。第一次使用需要從 Hugging Face 下載 FP32 MaskFormer 模型， 之後瀏覽器通常會保留下載快取。FP32 ONNX 模型約 166 MB，第一次載入需要較長時間。按下「停止分割」會釋放模型執行資源，但瀏覽器快取檔案仍會保留。
