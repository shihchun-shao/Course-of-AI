YOLOv4-tiny 本頁使用 YOLOv4-tiny ONNX 模型與 ONNX Runtime Web，在使用者自己的瀏覽器中進行物件偵測。

YOLOv4-tiny 如何偵測物件？

① Input Image將 Webcam 畫面縮放並 letterbox 到 416 × 416。
② CNN Feature Extraction利用卷積神經網路擷取不同尺度的影像特徵。
③ Multi-scale Detection使用兩個不同尺度的輸出層，同時處理較大與較小的物件。
④ Bounding Box預測物件中心位置、寬度與高度。
⑤ Object Classification對 COCO 80 個物件類別計算分類分數。
⑥ Confidence結合 Objectness 與類別分數，得到每個候選框的 Confidence。
⑦ NMSNon-Maximum Suppression 移除重疊的重複框，保留代表性最高的結果。
